Privacy Policy

Last updated: September 17, 2026

Sticker.pi Testnet uses Pi SDK authentication and processes only the information needed to operate the test app, including the Pi user ID and username returned after user authorization.

Authoritative gameplay data may include level, XP, daily streak, sticker collection, pack inventory, duplicates, challenge statistics, limited anti-abuse timestamps and verified Testnet transaction identifiers. A non-authoritative display cache may also be stored on the user's device.

Sticker.pi never asks users for, stores or needs a Pi Wallet passphrase, private key or seed phrase.

Supported Testnet transactions use Pi Network's official SDK and APIs and are verified server-side. Vercel and Upstash may process minimal technical data required to host the test service and persistent database.

This build is for development and testing. Test-Pi has no Mainnet value, and Testnet gameplay data may be reset as the service evolves.

Peer-to-peer exchange is not active. The controlled A2U developer test is hidden from normal use and is limited to explicitly invited Testnet testing.
